# 2026-05-23 — project kickoff

First working session. Established the project scope, architecture, and parts list end-to-end. No hardware yet.

## What was decided today

### Architecture — hybrid ESP32 + Pi Zero 2 W

After exploring three architectures (Pi-only, ESP32-only, hybrid), settled on the hybrid:

- **ESP32**: always-on monitor, real-time RF transmit (CC1101), native CAN bus (TWAI), deep sleep at sub-mA
- **Pi Zero 2 W**: 5" HDMI touchscreen UI, map display, web UI for home monitoring, MQTT publisher
- UART communication between them, ESP32 power-gates the Pi via a logic-level AO3401A P-MOSFET

Rationale: the Pi's WiFi + Linux is what makes home monitoring + maps possible. The ESP32's sub-mA deep sleep is what makes 24/7 battery monitoring possible without draining the car. Each does what it's good at.

### Connection: OBD-II only

Single-point connection through the OBD-II port via a passive Y-splitter:
- Pin 16 (+12V, always-hot) → fused 12V input
- Pin 4/5 (GND)
- Pin 6 (CAN-H), Pin 14 (CAN-L) → SN65HVD230 transceiver

Y-splitter keeps the port available for scan tools. No splicing into the car's harness. 15-minute reversible install.

### Compustar trigger: software-synthesized Keeloq RF

The car has a Compustar 1WSHR-PRO FOB (FCC ID 7087A-R762A433) already installed. The brain is somewhere behind the dash but not visually accessible without disassembly.

Instead of finding the brain's hardwire start input, we'll have the ESP32 transmit a valid Keeloq packet over 433.92 MHz via a CC1101 module. Keeloq has been academically broken; with owner-access to the FOB the practical attacks (chip EEPROM read, manufacturer-key databases) make this very feasible.

Plan:
1. SDR capture of FOB transmissions (RTL-SDR Vomeko dongle on hand)
2. URH analysis to identify framing, serial, function codes
3. Extract device key (Flipper Zero database first, PICkit fallback)
4. MicroPython Keeloq encoder driving CC1101

## Compustar discovery photos

Found the brain area while exploring under-dash:
- Identified factory Siemens VDO ECU (D53K label) — not the Compustar
- Spotted the Compustar brain partially obscured behind wiring tape
- Could not photograph the brain's model number despite trying — too tight an angle
- Identified the Compustar windshield antenna (small black 3-LED wedge top-center of windshield)

The model-number obstacle is what pushed us from "find the brain's start trigger wire" to "synthesize the RF packet ourselves." Better outcome anyway — fully reversible install.
