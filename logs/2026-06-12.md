# 2026-06-12 — dashboard: NTP time + graph hover tooltips (fw 2.0)

Three dashboard improvements to the S3 firmware: NTP time sync, a 6-hour
re-sync, and per-point hover tooltips on every graph (value + when).
These tie together — the hover "when" needs a real wall-clock, which is
what NTP provides.

## NTP time sync

- On WiFi STA connect, `configTzTime(TZ, "time.windows.com",
  "pool.ntp.org")` kicks SNTP. `time.windows.com` is primary,
  `pool.ntp.org` the fallback.
- Timezone is a single config constant `TZ_INFO = "MST7MDT,M3.2.0,M11.1.0"`
  (Mountain / Edmonton, with DST). It only affects on-device localtime;
  the dashboard formats per-sample timestamps in the *browser's* own
  timezone, so the displayed times are right regardless.
- **Re-sync every 6 h** (`NTP_RESYNC_MS`) to correct drift. Plus a
  retry-until-synced: if the first sync after connect is too early, the
  loop retries every 30 s until the clock reads a plausible year.
- No NTP in AP-fallback mode (no upstream).
- `/json` gained `epoch` + `time_ok`; the footer shows a live clock
  (or "no NTP" until synced).

Verified after OTA: `time_ok=true`, epoch resolved to **2026-06-12
9:28 AM local** — synced within seconds of boot.

## Timestamped history

- `Sample` gained a `uint32_t ts` (unix epoch when sampled; 0 if NTP
  hadn't synced yet).
- `/history` CSV now leads with a `ts` column:
  `ts,vbatt,temp,heap_kb,disk_kb,net_in,net_out,rssi`.
- The LittleFS history format changed, so the magic bumped
  `VOLT`→`VOL3`. **The old 24 h buffer is discarded once** on this
  flash (the loader rejects the old magic) — graphs rebuild from
  empty over the next day. Acceptable one-time loss.

## Graph hover tooltips

Every graph (voltage, temp, free mem, disk, net in/out, RSSI) now
shows, on mouse-over:

- the **value** at that point (right decimals + unit), and
- **when** it was sampled — the absolute local timestamp from the
  point's `ts`, or, for pre-NTP samples (`ts==0`), a relative
  "Xm ago" derived from the 60 s sample spacing.

Implementation: the chart renderer was refactored to keep each
graph's data + timestamps in a `CHARTS` map, so a `mousemove` can
redraw the line with a vertical guide + a dot on the nearest point and
position a shared tooltip near the cursor. `mouseleave` clears it.
Cursor is a crosshair over the canvases. Pure client-side; no extra
server load (the data was already fetched for the graphs).
