## Why surf, not Chromium — the gist

Chromium reliably OOM-killed itself on the Pi Zero 2 W (512 MB total)
while loading the dashboard. Surf (suckless WebKit2GTK) handles the
same page plus Leaflet at ~60 MB RSS without OOM, so it's the new
default. Chromium is still apt-installed by `provision.sh` as a
fallback for hardware with more headroom.

Documented in `docs/10-pi-setup.md` under a new "Why surf, not
Chromium" section.

## Dashboard map view + toggle

The dashboard now ships with **two views**:

- **Gauges view** (default): the existing battery/RPM/speed/coolant/
  throttle/fuel gauges + control buttons + trip log + events feed
- **Map view**: an embedded Leaflet map, centered (by default) on
  Edmonton city center with OSM raster tiles

A floating button in the top-right corner toggles between them.
Mouse-click in a regular browser, touch-tap on the Elecrow screen —
identical behavior. The choice is persisted to `localStorage` so a
`vroom.service` restart that reloads the page doesn't bounce the
operator back to gauges if they were watching the map.

### Configuration knobs

In `pi/app/config.py`:

```python
MAP_DEFAULT_CENTER = (53.5461, -113.4938)  # Edmonton city center
MAP_DEFAULT_ZOOM = 12
MAP_TILE_URL = "https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png"
MAP_TILE_ATTRIBUTION = '&copy; <a href=...>OpenStreetMap</a> contributors'
```

Edmonton is the shipped default because it's a public landmark — change
this constant for your install. The Jinja template renders all four
into JS land via `tojson`, so anything you set in Python flows through
without template changes.

### Implementation notes

- **Lazy Leaflet init**: the map JS is only constructed the first time
  the toggle is tapped. A kiosk operator who only ever looks at gauges
  never pays the tile-fetch cost.
- **Hidden vs. unmounted**: the map container starts `display:none`,
  which means Leaflet doesn't render tiles for an invisible div. On
  show, `invalidateSize()` is called so Leaflet recomputes its
  viewport (Leaflet famously misbehaves if its container was hidden
  at construction).
- **Subresource integrity**: both the Leaflet CSS and JS `<link>` /
  `<script>` tags have `integrity="sha256-..."` hashes pinned. If
  unpkg ever serves a different file, the browser refuses to load
  it. (Update the hashes if you bump the Leaflet version.)
- **CDN, not vendored**: matches the precedent set by the slypi-side
  `/home/node/map.html` standalone map. If the Pi is offline (no LAN
  Wi-Fi), the map view shows the page chrome but no tiles. The
  gauges view doesn't need the CDN. A future improvement is vendoring
  Leaflet into `pi/app/display/static/vendor/` so the dashboard
  works fully offline — deferred until/unless that's needed.
